## 📋 Descripción

Digital Money House es una aplicación fintech completa que simula una billetera virtual bancaria. Permite a los usuarios registrarse, autenticarse, consultar su saldo y actividad, gestionar tarjetas de crédito/débito, realizar transferencias y pagar servicios de forma segura y fluida.

## ✨ Funcionalidades Principales

- **Autenticación y Seguridad**: Registro, inicio de sesión con JWT y validación de sesiones mediante Middleware de Next.js.
- **Dashboard Financiero**: Visualización de saldo disponible, CVU, y últimos movimientos transaccionales.
- **Gestión de Tarjetas**: Alta, consulta y asociación de tarjetas bancarias.
- **Ingreso de Dinero y Transferencias**: Carga de fondos y pagos simulados en tiempo real.
- **Perfil de Usuario**: Administración de datos personales, métodos de pago y descarga de comprobantes.

## 🛠️ Stack Tecnológico

- **Framework**: Next.js (Pages Router con Server-Side Rendering y Middleware)
- **Lenguaje**: TypeScript (Strict Mode)
- **UI Components**: Material UI (MUI v5) & Custom CSS Modules
- **Gestión de Estado**: Context API + Custom Hooks
- **Servicios API**: Axios / Fetch con interceptores para token JWT

## 🚀 Inicio Rápido

```bash
# 1. Clonar el repositorio
git clone https://github.com/lucaszhh/digital-money-house.git
cd digital-money-house

# 2. Instalar dependencias
npm install

# 3. Iniciar entorno de desarrollo
npm run dev
```

Abre `http://localhost:3000` en tu navegador.
